# Gemini Batch Image Generator

Google Gemini에서 블로그용 이미지를 순차적으로 자동 생성하는 Chrome 확장프로그램입니다.

## 주요 기능

- **공통 스타일 + 개별 프롬프트 조합** — 공통 스타일을 한 번만 입력하고, 개별 프롬프트만 바꿔가며 일괄 생성
- **전체 프롬프트 붙여넣기** — `[공통 스타일]`, `[메인 썸네일]`, `[소제목2]` 등 섹션 태그로 자동 분류
- **순차 자동 전송** — 프롬프트 입력 → 전송 → 생성 완료 대기 → 다음 프롬프트 자동 반복
- **이미지 자동 다운로드** — 생성된 이미지를 자동으로 감지하여 폴더별로 다운로드
- **자동 폴더명 생성** — `Gemini_MMDD_인포그래픽_제목` 또는 `Gemini_MMDD_실사_제목` 형식
- **프롬프트 prefix 자동 분기** — 공통 스타일에 따라 인포그래픽/일반 이미지 prefix를 자동 적용
- **상태 저장/복원** — 입력 내용이 자동 저장되어 브라우저를 닫아도 유지

## 설치 방법

1. 이 저장소를 클론 또는 다운로드
2. Chrome에서 `chrome://extensions` 접속
3. **개발자 모드** 활성화
4. **압축해제된 확장 프로그램을 로드합니다** 클릭 → 이 폴더 선택

## 사용 방법

1. [Gemini](https://gemini.google.com)에 접속
2. 확장프로그램 아이콘 클릭 → 사이드 패널 열기
3. **공통 스타일** 입력 (예: 해상도, 팔레트, 무드 등)
4. **개별 프롬프트** 추가 (또는 전체 텍스트를 붙여넣기 영역에 붙여넣기)
5. **순차 생성 시작** 클릭

## 파일 구조

```
manifest.json    — Chrome 확장프로그램 설정
background.js    — 서비스 워커 (사이드 패널, 다운로드 처리)
content.js       — Gemini 페이지 조작 (입력, 전송, 대기, 다운로드)
popup.js         — 사이드 패널 UI 로직
popup.html       — 사이드 패널 UI
```

## 요구사항

- Chrome 브라우저 (Manifest V3)
- Google Gemini 접속 가능한 계정
